# Weather-App

This is a simple weather application that shows the current weather of a city.

## Setup

1.  Clone the repository.
2.  Create a `config.js` file in the root of the project.
3.  Copy the content of `config.example.js` to `config.js`.
4.  Replace `"YOUR_API_KEY"` with your OpenWeatherMap API key.
5.  Open `index.html` in your browser.
